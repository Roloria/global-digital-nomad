# 方法论 / Methodology

## 1. 数据收集流程

```
┌──────────────────┐
│ 公开数据源抓取    │ Nomad List / Numbeo / 旅游局
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 社区实地调研      │ GitHub Issues / Discord
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 交叉验证         │ 多源对照 / 异常剔除
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 评分校准         │ 维护者复核
└────────┬─────────┘
         ↓
┌──────────────────┐
│ PR 发布          │ 数据透明，可追溯
└──────────────────┘
```

## 2. 评分标准详解

### 2.1 网络（Internet）
- **9–10**：5G / 光纤全国普及，办公场所 Wi-Fi ≥ 100 Mbps
- **7–8.9**：4G/5G 覆盖好，办公 Wi-Fi ≥ 50 Mbps
- **5–6.9**：4G 覆盖可，Wi-Fi ≥ 25 Mbps
- **< 5**：网络不稳定，远程办公困难

### 2.2 社群（Community）
- **9–10**：活跃的 Nomad List 社群 + 多个 CoWorking + 每周 ≥ 5 场 Meetup
- **7–8.9**：稳定社群，月 ≥ 3 场 Meetup
- **5–6.9**：少数 CoWorking + Meetup，需主动寻找
- **< 5**：几乎无可识别的游民社群

### 2.3 生活（Fun）
- **9–10**：国际都市水准 — 文化、餐饮、夜生活、娱乐多样
- **7–8.9**：丰富但稍单一
- **5–6.9**：满足基本娱乐需求
- **< 5**：娱乐选项稀缺

### 2.4 安全（Safety）
- **9–10**：全球最安全国家之一（如日本、新加坡、瑞士级）
- **7–8.9**：犯罪率低，夜间独自外出安全
- **5–6.9**：大部分地区安全，需注意特定区域
- **< 5**：常见暴力/偷窃风险

### 2.5 英语（English）
- **9–10**：全民英语普及（如新加坡、北欧）
- **7–8.9**：旅游业/服务业英语流利
- **5–6.9**：年轻一代英语可沟通
- **< 5**：语言障碍显著

### 2.6 步行（Walkability）
- 反映日常通勤便利度、人行道质量、公共交通衔接

### 2.7 空气（Air Quality）
- 基于 PM2.5 年均值 + AQI 综合评估
- 海岛/山区/北欧城市通常 ≥ 8，污染大城市通常 ≤ 5

### 2.8 女性友好（Female Friendly）
- 性别平等指数 + 性骚扰/性侵统计 + 法律保护

### 2.9 LGBTQ+
- 同性恋合法化 + 反歧视法律 + 社会氛围 + Pride 活动

### 2.10 夜生活（Nightlife）
- 酒吧/俱乐部密度 + 24h 文化 + 安全夜间出行

### 2.11 安静指数（Peace）
- 反映噪音、拥挤度、可专注性
- 海岛小镇 8+，大都市中心 4–5

### 2.12 种族包容（Racial Tolerance）
- 外籍人口比例 + 移民友好政策 + 多元氛围

## 3. 综合分权重逻辑

| 维度 | 权重 | 理由 |
|---|---:|---|
| 社群 | 1.2 | 远程工作的核心痛点之一 |
| 安全 | 1.2 | 长期居住的最低门槛 |
| 网络 | 1.0 | 工作基础设施 |
| 生活 | 1.0 | 影响体验 |
| 英语 | 0.9 | 国际沟通基础 |
| 女性友好 | 0.8 | 包容度重要 |
| 步行 | 0.7 | 日常通勤 |
| 空气 | 0.7 | 长期健康 |
| LGBTQ+ | 0.6 | 包容度 |
| 种族包容 | 0.6 | 多元氛围 |
| 安静 | 0.6 | 专注力 |
| 夜生活 | 0.5 | 锦上添花 |

合计 9.8（已归一化）。

## 4. 数据局限

- **主观性**：部分维度（如生活、女性友好）难以完全量化
- **时效性**：签证政策、汇率、安全局势变化快，建议 6 个月内参考
- **覆盖偏差**：英语国家的数据更完整，非英语国家可能低估
- **样本偏差**：Nomad List 用户偏年轻、男性、技术背景
