# 数据来源 / Data Sources

本文档列出了数据采集过程中参考的主要来源。

## 主要来源

### 1. Nomad List (nomadlist.com)
- **类型**：数字游民社区 + 数据平台
- **用途**：评分基线、游民人数估算
- **License**：CC BY-NC（引用需注明）
- **API**：有官方 API

### 2. 各国家/地区旅游局官方数据
- **示例**：
  - 🇹🇭 Tourism Authority of Thailand
  - 🇵🇹 Visit Portugal
  - 🇪🇸 Turespaña
  - 🇯🇵 Japan National Tourism Organization
- **用途**：签证政策、入境要求

### 3. Numbeo (numbeo.com)
- **类型**：众包生活成本数据库
- **用途**：月成本估算、犯罪率

### 4. Airbnb / Booking 长租数据
- **用途**：房租水平估算

### 5. Speedtest.net / Cloudflare Radar
- **用途**：网络速度验证

### 6. Wikipedia / World Bank / OECD
- **用途**：宏观经济数据、治安数据、性别平等指数

### 7. Flatio 数字游民报告
- **URL**：flatio.com/blog/digital-nomad-reports/
- **用途**：游民趋势、签证数据

### 8. 各国数字游民签证官方页面
- 已收录 27 国 / 地区的官方签证说明

### 9. 中国境内专项数据源
- **Nomad Watch 中国页**：nomad.watch/countries/CN/cities — 33 城评分/成本基线
- **nomads.com**：逐城实测（月成本、网速 Mbps、空气质量 AQI）
- **RemoteAI-Nomads（GitHub cubxxw）**：25+ 国内数字游民基地名录（安吉 DNA、大理 NCC/CYC、资阳 DNβ 等）与地方政策补贴清单
- **xuf-95/digital-nomad**：国内数字游民社区名录（DNA 安吉、DNCN 余村、NCC 大理、上海漕泾国际村、北京中关村国际社区）
- **政策来源**：国家移民管理局（240h 过境免签、45 国免签、海南 59 国 30 天免签）、云南日报/云岭先锋（大理旅居人口）、安吉/杭州日报、GIS 政策文件

## 辅助来源

- GitHub Awesome 数字游民列表
- Reddit r/digitalnomad、r/expats
- 各城市 CoWorking 官网（WeWork、Industrious 等）
- 各国移民局、税务局公告

## 引用规范

在使用本项目数据时，建议：

```
数据来源：全球数字游民计划 (github.com/Roloria/global-digital-nomad)
原始数据：Nomad List 等公开来源
```
