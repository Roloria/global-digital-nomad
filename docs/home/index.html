同步

FAQ

常见问题

更多疑问欢迎在 GitHub Discussions 里提问，或在腾讯文档留言。

Q1评分是怎么来的？+

每座城市按网络、社群、生活、安全、英语、步行、空气、女性友好、LGBTQ+、夜生活、安静指数、种族包容共 12 个维度加权评分，月成本作为独立数据列呈现。权重与公式完全公开，综合分人人可复算。

Q2数据多久更新一次？+

没有强制周期，由社区持续维护。任何人都可以在表格或榜单页提交更新，PR 合并后对应城市的「最后更新」会自动刷新；CI 数据保鲜哨兵会在数据停滞超 7 天时自动提醒社区。

Q3我不懂代码，能参与吗？+

能。打开腾讯文档就能像编辑在线表格一样直接修改，改动会自动进入 GitHub 审核流程，全程不需要任何编程知识。匿名提交也可以：榜单页的提交表单会自动帮你创建 GitHub Issue。

Q4数字游民签证怎么选？+

热门选项包括葡萄牙 D7/D8、西班牙数字游民签证、爱沙尼亚与捷克游民签证，常见门槛为月收入 2,000–3,500 美元与健康保险。榜单为每座城市标注了当前推荐签证类型，具体申请请以当地移民局官网为准。

Q5预算有限，可以去哪儿？+

河内、岘港、暹粒、开罗的月成本约 800 美元；大理 850 美元就能住进综合分 7.5 的城市。打开完整榜单，按「月成本」一列筛选即可。
