💡 提交指南

本表单支持两种用途：

  • 更新现有城市：基于你的实地经历修正某项评分
  • 添加新城市：填写你认为值得加入榜单的目的地

📋 必填内容：

  • 城市名 + 国家（必填，否则无法定位）
  • 经历描述：你在这里居住/工作的时长、季节、实际花费、社区参与情况等
  • 数据来源：你的判断依据（Nomad List、Numbeo、个人经验等）

💾 提交后数据保存在你的浏览器本地，可一键导出为 JSON 或直接通过 GitHub Issue 上报到开源项目。
